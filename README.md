# React To-Do List App

A simple and user-friendly To-Do List application built with React. This app allows users to create, edit, delete, and view finished tasks. It uses `localStorage` to save tasks, ensuring they persist even after the browser is closed or refreshed.

## Features

- **User-Friendly Interface**: Intuitive design for managing tasks with ease.
- **Create Tasks**: Add new tasks by simply typing in and clicking "Add".
- **Edit Tasks**: Modify your tasks by selecting the "Edit" option.
- **Delete Tasks**: Remove unwanted tasks with just a click.
- **View Finished Tasks**: Keep track of completed tasks in a separate section.
- **Local Storage**: Your tasks are saved in the browser's localStorage, so they won't be lost on refresh or page close.

## Technologies Used

- **React**: The app is built using React for fast, dynamic user interface rendering.
- **LocalStorage**: Tasks are stored in the browser's localStorage, allowing data persistence.

## How It Works

1. Add new tasks by entering a task in the input field and clicking the "Add" button.
2. View your current tasks in the "To-Do" section.
3. Mark tasks as completed to move them to the "Finished" section.
4. Edit or delete tasks directly from the task list.
5. All tasks are saved in localStorage for persistence.
